# tnm-test-fixtures

Синтетические тестовые лендинги для проверки Trust Network Monitor
(краулинг, история изменений, AI-анализ находок).

- `nutra-real.html` — обычный, добросовестный лендинг вымышленного БАД
  "LumaSlim".
- `nutra-deepfake.html` — тот же бренд, но с признаками злоупотреблений:
  вымышленный celebrity endorsement ("Morgan Vale" — не реальный человек),
  завышенные обещания, таймер искусственной срочности, накрученные отзывы.

Обе страницы — вымышленный продукт/бренд, ни один реальный человек,
компания или ТВ-шоу не используются. Создано для внутреннего QA
fraud-детекции, не является реальным маркетинговым материалом.
